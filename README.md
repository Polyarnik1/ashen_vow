# Пепельный Обет — рыцари бледной луны

Пиксельная dark fantasy RPG с видом сверху и пошаговыми боями «с окном уклонения» в духе Deltarune, но со своими механиками. Работает в браузере на компьютере и на телефоне.

Рыцарь Ардан восстаёт из пепла, когда трескается печать, под которой сто лет назад заперли Забытого Короля. Пролог, шесть глав, две концовки — исход зависит от того, щадишь ли ты врагов.

## Как играть

Открой `index.html` через любой локальный веб-сервер (музыка грузится из папки `music/`, поэтому двойной клик по файлу может не сработать):

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Или включи GitHub Pages: **Settings → Pages → Deploy from a branch → main / (root)**.

### Управление

| | Компьютер | Телефон |
|---|---|---|
| Движение | Стрелки / WASD | Джойстик |
| Действие, выбор, парирование | Enter / Пробел / Z | A |
| Назад, бег, точное движение | Shift / X | B |
| Меню | Esc / C | ☰ |

### Бои

- **УДАР** — останови полосу в центре.
- **ДЕЙСТВИЕ** — поговори с врагом, наполни его «покой» и пощади.
- **МОЛИТВА** — тратит Дух (шкала слева).
- **ВЕЩИ** и **ЩИТ** (урон вдвое меньше).
- В ход врага уклоняйся щитом-искрой. Нажми кнопку действия в миг удара — **парирование**. Пролетай вскользь мимо снарядов, чтобы копить Дух.

Сохранение — у голубых Свечей Обета.

## Структура

```
index.html        собранная игра (всё в одном файле, кроме музыки)
music/            21 трек (mp3, 80 кбит/с)
src/              исходники по модулям
  01_engine.js    холст, ввод, звуковой синтезатор, музыка
  02_gfx.js       процедурный пиксель-арт: тайлы, персонажи, портреты
  03_monsters.js  спрайты монстров и рыцаря в бою
  04_core.js      состояние, предметы, диалоги, скрипты сцен
  05_world.js     карты, освещение, частицы, NPC, враги на карте
  06_battle.js    боевая система
  07_patterns.js  атаки врагов
  08_enemies.js   бестиарий и боссы
  09_maps.js      10 локаций
  10_story.js     сюжет, диалоги, магазины, концовки
  11_main.js      титульный экран, меню, катсцены, главный цикл
tools/            шаблон HTML и скрипт сборки
```

### Сборка из исходников

```bash
npm install
npm run build   # пересобирает index.html из src/
```

## Музыка

Треки из сборника *Dark Fantasy (Slowed)* и «Seal of the Forgotten King». Шрифт — [Pixelify Sans](https://fonts.google.com/specimen/Pixelify+Sans) (SIL OFL).
